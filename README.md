# Market Lens — public snapshot

Read-only portfolio and FRED PPI snapshot. The password screen is a visual entry screen, NOT access control. All deployed data is public.

FactSet workbook/band/EPS data, API routes, API keys, local environment files and private credentials are excluded.

Data is updated only by exporting a new snapshot on the owner's PC and publishing a commit. GitHub Pages deploys the main branch root. No automatic live collection runs here.

See data/manifest.json for the export timestamp and closing-price date.
